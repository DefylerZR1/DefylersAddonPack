# Nemesis branding asset drop

Branding files:

- `nemesis-icon-source.png`: high resolution transparent source.
- `nemesis-icon.png`: 256 x 256 transparent PNG.
- `nemesis-icon.tga`: 256 x 256, 32-bit RGBA game asset used by `Nemesis.toc`.
- `nemesis-splash.tga`: transparent or opaque RGBA, preferably 1024 x 512 (2:1).

Keep important splash artwork and lettering inside a 5% safe margin. TGA should be 32-bit with an alpha channel. The final Nemesis icon is installed; the splash remains pending.
