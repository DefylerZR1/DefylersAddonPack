# Defylers Addon Pack v2.0.0

This is the first full release of Defylers Addon Pack for WoW Forever.

## Highlights

- Expanded DXM Auction House scanning, valuation, crafting, salvage, vendor, earnings, and ledger tools.
- Isolated neutral Auction House scans so they never contaminate faction prices or website market reports.
- Added DQA quest-objective highlights, creature kill counts, self-critical-strike rewards, and Mage book tracking.
- Added configurable book locations, automatic map and world-map pins, bank detection, and smaller nearby book markers.
- Improved Defyler UI window controls, suite navigation, saved layouts, and stability.
- Updated Forever Settings controls and client readback.
- Included Defyler Damage Meter, DDQ, Forever Core Fixes, and Nemesis in the complete suite.

The website package includes DXM Relay 1.1.0. The CurseForge and GitHub package contains addons only.
